# Gestión de Tareas con React y Flask

Este proyecto es una aplicación web para la gestión de tareas que utiliza React en el frontend y Flask en el backend. La aplicación incluye funcionalidades avanzadas como una Matriz de Eisenhower, gráficos de estadísticas de tareas y una interfaz optimizada para el manejo eficiente de tareas.

## Características

- Crear, editar, eliminar y buscar tareas.
- Cambiar el estado de las tareas (completadas/pendientes).
- Organizar las tareas en una Matriz de Eisenhower (Hacer Primero, Hacer Más Tarde, Delegar, No Hacer).
- Visualización de estadísticas de tareas mediante gráficos.
- Modo claro/oscuro.
- Ordenar tareas por fecha o estado.
- Diseño responsivo y amigable.

## Tecnologías Utilizadas

### Frontend
- **React**: Framework para crear interfaces de usuario dinámicas.
- **React Chart.js 2**: Librería para gráficos estadísticos.
- **CSS**: Para el diseño y estilos personalizados.

### Backend
- **Flask**: Framework web en Python.
- **Flask-CORS**: Para manejar solicitudes de diferentes orígenes.
- **SQLite**: Base de datos ligera para almacenar tareas.

### Otras Herramientas
- **Axios**: Cliente HTTP para realizar peticiones al backend.
- **Chart.js**: Librería base para visualización de datos.
- **GitHub**: Para control de versiones y colaboración.
